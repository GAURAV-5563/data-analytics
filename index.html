About this portfolio

Curiosity, backed by data.

These projects use Python, Pandas, NumPy, Matplotlib, and Scikit-learn to turn example datasets into clear analyses. The portfolio page and chart previews are hosted as a static GitHub Pages site. The Python Streamlit dashboards are included as source code in the repository and need a Python app host to run interactively.
